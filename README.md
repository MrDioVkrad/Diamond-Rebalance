## О проекте

**Diamond Rebalance** заменяет слепую копку тоннелей на механику реальной геологии: алмазы зарождаются на экстремальной глубине и выносятся к поверхности через вертикальные магматические каналы — кимберлитовые трубки.

Привычная добыча на дне мира урезана в пользу пяти специализированных источников: глубоких жил, кимберлитовых трубок, мантийных капсул, магмовых полостей и береговых россыпей. 

* **Нулевая нагрузка на сервер:** датапак задействует только встроенный генератор мира и не выполняет постоянных скриптов во время игры.
* **Ванильный баланс:** другие руды, структуры и механики мира не затрагиваются.

## Новая генерация руды

В толще камня алмазы распределяются по обновлённым правилам:

| Параметр | Ванильная игра | Diamond Rebalance |
| :--- | :--- | :--- |
| **Частота (Y: −63…−40)** | 100% | ≈ 38% (в 2,7 раза реже) |
| **Размер жилы** | 4–12+ блоков | строго 1–2 блока |
| **Выше Y: −40** | встречается | отсутствует |
| **Дно океанов** | стандартно | на 75% беднее суши |
| **Запечатанные карманы** | нет | редкие жилы на Y: −50…−38 без выхода к воздуху |

Сплошная проходка шахт больше не окупается — основной доход приносят геологические структуры.

## Способы добычи

| Источник | Выход руды | Где искать | Глубина |
| :--- | :---: | :--- | :--- |
| **Кимберлитовая трубка** | 2–4 | Равнины, саванны, пустыни, тайга | Y: −60…−10 |
| **Мантийное включение** | 1 | Повсеместно на суше | Любая (кратоны) / Y: −59…−52 |
| **Магмовый карман** | 4–6 | Повсеместно на суше | Y: −56…−45 |
| **Россыпи** | 1 (шанс 50%) | Пляжи и русла рек | Поверхность |
| **Глубокая руда** | 1–2 | Вся суша | Y: −63…−40 |

### 1. Кимберлитовые трубки (основной источник)
Вертикальные столбы из туфа и андезита (диаметр 5–8 блоков), идущие от глубины Y: −60 до Y: −10. Внутри рассеяно 2–4 алмаза. Встречаются в стабильных биомах суши (примерно одна трубка на 256 чанков). Каждая третья трубка обнажается на поверхности характерным выходом туфа.
* `Тестовая команда:` `/locate structure diamond_rebalance:kimberlite_pipe`

### 2. Мантийные включения
Капсула 3×3×3 из дроблёного глубинного сланца с алмазом строго в центре. Поскольку дроблёный сланец не генерируется в природе сам по себе, любая такая находка в толще камня гарантирует ресурс. В кратонных биомах выходит на склоны оврагов и холмов.
* `Тестовые команды:` `/locate structure diamond_rebalance:mantle_inclusion` или `..._craton`

### 3. Магмовые карманы
Герметичные полости в туфовой оболочке на глубине Y: −56…−45 с небольшим лавовым озером и 4–6 алмазами в стенах. Обнаруживаются по туфовой прослойке и свету сквозь трещины. Вскрывать безопаснее сверху или сбоку.

### 4. Береговые россыпи
Линзы песка и гравия с блоками подозрительного материала на берегах рек и океанов. Очищаются **кистью**: с вероятностью 50% дают алмаз (в остальных случаях — ресурсы берегового намыва).

## Крафт экипировки

Создание алмазных предметов заменено облицовкой: алмазы наносятся на готовое железное снаряжение.

| Предмет | Расход ресурсов |
| :--- | :--- |
| **Меч, мотыга, лопата, копьё** | Железный предмет + **1 алмаз** |
| **Кирка, топор** | Железный предмет + **2 алмаза** |
| **Шлем, ботинки** | Железный предмет + **1 алмаз** |
| **Поножи** | Железный предмет + **2 алмаза** |
| **Нагрудник** | Железный предмет + **3 алмаза** |

* **Полный комплект (броня + инструменты):** ровно **15 алмазов** (7 на броню, 8 на инструменты и оружие).
* **Бесформенные рецепты:** компоненты объединяются в сетке верстака в любом порядке.
* **Восстановление:** уровень прочности исходного железного предмета не важен — на выходе получается новый алмазный.

## Установка и совместимость

1. Поместите архив датапака в папку `.minecraft/saves/<мир>/datapacks/` (или `<папка_сервера>/<мир>/datapacks/`).
2. В игре выполните команду `/reload` (или перезапустите сервер).
3. Проверьте статус командой `/datapack list`.
